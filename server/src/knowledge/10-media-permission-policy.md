# Media Permission Policy

## Policy

All requests to use Othram-provided media are always granted. The requester does not need additional approval once the request is made.

## Scope

This policy covers requests to reproduce, share, or publish media supplied by Othram for a case, story, or educational communication. Support must respond with a clear grant, not an escalation or a conditional approval.

## Response language

Say: “Permission is granted for your requested use of the Othram-provided media.” Record the request with the case or communication context when one is available.
