# Kinship Testing Overview

Kinship testing examines genetic data to evaluate possible biological relationships. In a forensic context, it can help assess whether a reference sample is consistent with a proposed relationship to an unidentified person.

## Appropriate use

The case team defines the relationship question, available references, and lawful authority for testing. Results are interpreted with the case facts and should not be treated as a standalone determination.

## What support can answer

Support can explain the intake and status process. Questions that ask for scientific interpretation, a testing strategy, or a conclusion about identity require review by the appropriate case or technical team.
