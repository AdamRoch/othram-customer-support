# Evidence Submission Standard Operating Procedure

Use this procedure after a case is accepted and shipping instructions have been issued.

## Before shipment

1. Confirm the case reference and approved item list.
2. Record each item identifier, description, and current custodian.
3. Package each item separately to prevent transfer or damage.
4. Complete the required chain-of-custody documentation.

## At shipment

Use the carrier, destination, and tracking method provided for the case. Retain the tracking number and the signed or electronic transfer record. Report a damaged package, missed delivery, or chain-of-custody discrepancy to the case contact immediately.
