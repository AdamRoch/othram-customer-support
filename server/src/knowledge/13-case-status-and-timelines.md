# Case Status and Timelines

Case updates come from the case system. A status response should identify the current stage, whether a delay flag exists, and the system-provided expected timing when available.

## What support should not do

Do not promise a delivery date, estimate a new date from general experience, or infer progress from a missing record. If the case system lacks a required fact, escalate for a verified update.

## Identity check

A case number is enough for a status-level answer. Any request for information beyond status requires the email address on file or the appropriate authorized identity check.
