# Forensic Case Intake

Forensic case intake starts with case information, not a shipment. The submitting organization provides the facts needed to evaluate the requested work and receives instructions after review.

## Intake sequence

1. Submit case information through the authorized request process.
2. Receive and review a service quote.
3. Approve the quote before laboratory work begins.
4. Ship approved items using the case-specific instructions provided.

## Important boundary

Do not send evidence before the case team supplies the appropriate shipping instructions and case reference. The submitting organization remains responsible for its authority to submit materials.
