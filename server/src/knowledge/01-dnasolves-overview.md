# DNASolves Overview

DNASolves is a community DNA database that can help investigators generate leads in qualifying forensic cases. People who choose to participate may upload DNA data from a supported consumer test or submit a collection kit.

## How participation helps

An uploaded profile can be one data point in genetic-genealogy research. It may help investigators focus on possible relatives of an unidentified person or a person connected to a case. Participation does not promise a match, a case outcome, or contact from an investigator.

## Getting started

Use the DNASolves registration flow to create an account and review the current consent choices before submitting data. Questions about a specific investigation should go to the investigating agency.
